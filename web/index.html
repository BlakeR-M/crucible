Crucible

AI finds bugs. Most of them are wrong. This proves which ones aren’t.

Ask a model to review code and it hands you findings that sound right. Plenty are wrong. Crucible sends every finding to three separate verifiers whose job is to tear it down, and reports the ones still standing.

One recorded run against the bundled demo project raised 16 findings and reported 9. It cost 27 US cents. The full ledger is in the repo, and one command replays every decision in it on your machine.

Every agent action is checked against a written policy before it runs, and the whole run lands in a hash-chained ledger you can download from this page.

This deployment runs a free stand-in model, so have a play. Attach your own OpenAI or Gemini key and it reviews for real, including a public repository of yours pasted straight into the page. The code is standard-library Python, and it runs on your machine too:
